# External Data Sources

1. PaySim Kaggle dataset: https://www.kaggle.com/datasets/ealaxi/paysim1
2. PaySim dataset metadata: https://www.kaggle.com/ealaxi/paysim1/metadata
3. PaySim simulator paper citation: E. A. Lopez-Rojas, A. Elmir, S. Axelsson, "PaySim: A financial mobile money simulator for fraud detection," EMSS 2016.

The public PaySim dataset is synthetic and was generated using aggregated information from private transaction logs. The project therefore describes it as synthetic/realistic rather than as real customer banking data.
