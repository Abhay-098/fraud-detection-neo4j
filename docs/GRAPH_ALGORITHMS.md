# Graph Algorithms

Neo4j Graph Data Science is optional for the Review 2 prototype.

The project already works with Cypher-based relationship analysis. If Neo4j GDS is installed, `cypher/gds.cypher` demonstrates:

- PageRank for influential/high-centrality accounts
- Louvain for community discovery

These outputs are investigation indicators. A high PageRank score or membership in a dense community does not by itself establish fraud.
